Description
I aim to create an artefact that calculates how many kilowatts is used in a household over the course of a period of time by a single appliance. My initial idea is the washing machine as I can measure on/off using the motion sensor (or tilt sensor when door opens) on raspberry pi. I will hardcode the average usage of my machine cycle. I will apply the cost of this using the household bills and kw rate my house has. I hope to create a model that will count the number of times the machine was used and calculate the cost using the night rate, day rate and peak rate. I will use data from a database or create my own database using data collected from comparison websites to identify if my usage of a period of time: week/month/day could have been cheaper by using a different energy supplier. I could extend this project by outputting tips to the user of cheaper times to use the machine and or a better electricity provider suitable for my usage.
